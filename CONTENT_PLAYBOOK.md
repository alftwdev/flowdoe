# Cornerstone Flowstate — Content Marketing Playbook
*The operating manual for converting X/Threads viewers into Discord subscribers.*
*Last updated: Sept 26, 2026*

---

## 0. The One Rule

**Sell the insight. Gate the signal.**

Give away the framework (how to think). Lock the output (what to do today).
A viewer who understands the problem will pay for the answer.
A viewer who doesn't understand the problem won't pay for anything.

---

## 1. Tweet Length Rules (Hard Limits)

| Format | Limit | Why |
|--------|-------|-----|
| Main tweet (hook) | **≤ 240 chars** | Anything longer shows "Show more" — engagement dies |
| Thread tweet (T2, T3) | ≤ 260 chars | Replies get less preview space |
| First reply (CTA + link) | ≤ 280 chars | CTA doesn't need to breathe, just convert |

**Count before posting.** Line breaks count as characters. Blank lines cost 2 characters each.

**Golden rule:** If you need to re-read a tweet twice, cut it in half.

### What gets cut when too long:
- The most important line is usually at the bottom — and it never gets read
- "Show more" drops click-through by 60–80% on mobile
- The algorithm treats low dwell time as negative signal

### Tweet compression checklist:
- Remove filler openers ("A lot of people are...") → start with the tension
- Cut "the" and "a" where meaning holds
- Every line break is intentional — it should speed up reading, not slow it down
- One idea per tweet. If you have two ideas, that's two tweets.

## 2. SEO for X (What Gets You Found)

### Cashtags ($CLM, $CRF) — always in the body, not just the footer
X indexes cashtags for topic search. If `$CLM` or `$CRF` appears in tweet 1, you show up when someone searches those tickers. Don't bury them at the end — put them in the content naturally.

```
❌ Weak:  "The yield math says hold. $CLM $CRF #FinTwit"
✅ Strong: "$CLM at $6.38 = 22.8% yield. Fair value = $7.67."
```

### Hashtags: 3 max, only on the last tweet in a thread
Hashtags on the main tweet eat characters and look spammy. Put them in the last tweet (or first reply) only. Best for this niche: `#FinTwit #DividendInvesting #ClosedEndFunds`. Never more than 3.

### Timing for peak finance engagement on X:
- **8:30–9:15 AM ET** — market open window, highest finance traffic
- **3:30–4:15 PM ET** — market close recap traffic
- Weekend posts: any time (lower volume but lower competition too)

### What the algorithm rewards:
1. Replies in the first 30 minutes (most important signal)
2. Author engaging their own replies within 30 minutes (reply-back)
3. Copy-link shares (someone sharing the text, not just retweeting)
4. Profile visits after seeing the tweet (means the hook worked)

### What kills reach:
- External links in tweet 1 (deprioritized in feed)
- Posting the same hook structure multiple days in a row
- Low reply count relative to impressions (signals poor content)
- Mutes and "Not Interested" clicks (expensive negative signal)

## 3. Hook Methodology

The hook is the only thing most people read. If it doesn't create a question in their mind, they scroll.

### The 5 Hook Types (rotate these)

**1. The Tension Hook** — state a contradiction or paradox
```
"Selling $CLM at the lowest premium since Covid doesn't reduce risk. It realizes it."
```

**2. The Specific Number Hook** — real numbers create credibility instantly
```
"$CLM at $6.38 = 22.8% yield. Fair value at 19% = $7.67. That's a 20% gap."
```

**3. The "I see you" Hook** — name the exact pain your audience feels
```
"CLM/CRF holders this weekend: cost basis $7.50, slightly positive, paralyzed."
```

**4. The Contrarian Hook** — challenge the obvious take
```
"The RO isn't the risk. Selling into it is."
```

**5. The Countdown Hook** — urgency from a real event (never fake urgency)
```
"N-2/A filing expected in ~4 days. Here's what changes when it drops."
```

### Hook writing rules:
- First 40 characters appear as preview text in notifications — lead with the tension
- Ask yourself: "Would someone who doesn't know me read the second line?" If no, rewrite the first
- Never start with "I" — starts with the audience's problem, not your story
- One hook per post. Never stack two hooks — the reader doesn't know where to focus

## 4. Defining the Problem (The Research-First Loop)

Content that converts starts with the real pain, not a topic. Before writing, identify:

### 3 Questions to Answer Before Every Post:
1. **What is someone feeling right now about CLM/CRF (or the wheel, or the market)?**
   → Source: Discord screenshot, Grok query [1], X search for $CLM
2. **What are they doing wrong because of that feeling?**
   → The mistake (selling at lowest premium, skipping VRP filter, entering before earnings)
3. **What's the one insight that would change their decision?**
   → The framework (yield math, 84-day RO clock, IV-HV spread gate)

### Real pain points confirmed from community research (Sept 2026):
- "I can't decide if I should sell" → paralysis at cycle lows (wrong variable: cost basis)
- "N2 caught many off guard" → no automated EDGAR early warning
- "Does it take long time for the process to start?" → no timeline awareness
- "The waiting for the RO strategy is not working for me" → no systematic playbook
- "Sized out when Todd recommended us to" → dependent on manual human signal, not automated

**Rule: Every post must address ONE of these pain points explicitly or implicitly.**
If you can't connect the post to a documented pain point, it's probably not worth posting.

## 5. CTA Placement Rules

### Where the link lives:
| Location | Use |
|----------|-----|
| Bio (always) | Permanent. `bit.ly/cfx-ro` pointing to Gumroad |
| Pinned post | Updated monthly. Shows the best-performing hook + link |
| First reply (manual) | Posted ~2 min after the main thread auto-posts |
| Thread tweet 4 | Acceptable — but always less effective than first reply |
| Tweet 1 (main hook) | **NEVER** — kills reach |

### CTA language that converts vs. CTA language that doesn't:
```
❌ "Join my Discord for more signals"   — sounds like a pitch
❌ "Subscribe for full access"          — generic, no value promise
✅ "Live RO signal + entry zones: [link]"  — specific, tells them exactly what they get
✅ "Full 84-day RO calendar in bio"     — creates intrigue without the link in the main post
✅ "Subscribers saw this alert 3 days ago: [link]"  — proof of value before the ask
```

### The bit.ly scheme (separate tracking per campaign):
| Link | Campaign | Where used |
|------|----------|-----------|
| `bit.ly/cfx-ro` | CLM/CRF RO bait | Bait 1 CTAs, bio |
| `bit.ly/cfx-wheel` | Options wheel bait | Bait 2 CTAs |
| `bit.ly/cfx-morning` | Morning posture bait | Bait 3 CTAs |

Add UTM parameters when linking manually: `?utm_source=x&utm_medium=reply&utm_campaign=sept26`
bit.ly dashboard shows which campaign is converting. Double down on the winner.

## 6. Threads vs. X — Different Formats, Same Principle

### X: compression + cashtags + reply bait
- Punchy. Every line is a sentence.
- Cashtags in body for topic indexing
- Thread: max 3 tweets auto-posted; CTA in first reply (manual)
- Reply starters posted within 30 min to seed engagement

### Threads (Meta): story arc + personal voice + no hashtags
- Longer paragraphs allowed. Threads readers tolerate more context.
- Personal framing ("Saw someone post this...") outperforms declarative statements
- No hashtags — Meta confirmed they don't boost organic reach on Threads
- No emojis in the Threads API post (stripped automatically by the dispatcher)
- Story structure: someone's real problem → insight → the math → what it means → NFA
- End with something that humanizes: "Not financial advice. Just how I think through it."

### When to adapt the same angle for both:
Write the X version first (compression forces clarity). Expand for Threads by adding the story layer (who this is about, why the mistake makes sense, what most people miss).

## 7. Viewer → Subscriber Conversion Path

```
X impression
  → Hook creates a question in their mind ("what's the yield math?")
    → Reply or profile visit
      → Bio: "Live CLM/CRF signals + RO playbook ↓ [bit.ly/cfx-ro]"
        → Gumroad page: one job — convert to Discord member
          → Discord onboarding: #start-here + immediate value (free tier teaser)
            → Paid upgrade: see the live signal before it moves
```

### Where each stage breaks down and how to fix it:

| Stage | Symptom | Fix |
|-------|---------|-----|
| Low impressions | Under 500 impressions/post | Improve hook + reply on larger accounts first |
| Impressions but no replies | People read, don't engage | Add explicit reply bait ("What's your cost basis?") |
| Replies but no profile visits | Hook doesn't create curiosity about you | The hook is too generic — make it more specific to a real pain |
| Profile visits but no bit.ly clicks | Bio isn't compelling | Rewrite bio with Gumroad rewrite (see below) |
| bit.ly clicks but no Gumroad sales | Gumroad page doesn't convert | Proof is missing — add accuracy scorecard screenshot |
| Sales but Discord churn | No onboarding, no daily reason to stay | Build #start-here + daily signal post |

### Bio formula (rewrite monthly with Grok):
```

EDGAR watcher · RO playbook · Live signals
Discord + full playbook ↓
[bit.ly/cfx-ro]
```

## 8. Retention and Trust Building

Subscribers stay when they trust the signal. Trust is built through:

### 1. Accuracy scorecard (weekly — #free-data channel)
Show prediction vs. actual. Real numbers. Win rate. MTD accuracy.
Even a 70% win rate is compelling if shown transparently.
Free tier sees the outcome. Paid tier sees it in real time.

### 2. Timeliness proof
"N-2 filed Aug 14. Our alert fired same session. CLM dropped $0.41 in 3 days."
Screenshot + timeline = proof the signal leads the market.

### 3. The "I was wrong" post (once a month)
When a signal doesn't play out, own it publicly. Explain what the model missed.
This is the highest-trust content type. Very few finance accounts do it.
It also drives the most replies — people respect intellectual honesty.

### 4. Consistent voice
Every post should sound like the same person. Not "educational resource." Not "trading bot."
A person who runs this system with real money and is sharing what they see.
The Shawn Grady model: W2 paycheck → portfolio → living off the equity. That's the story.

### 5. Never over-promise
"CLM is going to recover" → don't say this
"At 22.8% yield, the income buyer support floor is structural" → say this instead
One is a prediction. One is an observation backed by math. Subscribers trust observations.

## 9. Content Mix (80/20)

| Type | % | What it looks like |
|------|---|-------------------|
| Discovery (no sell) | 80% | Specific tactic, contrarian take, teardown of a common mistake, short proof, question only your audience can answer |
| Offer (soft sell) | 20% | Shows the result or mechanism. Link in first reply only. Never "join my Discord." |

### Never post:
- Vague market commentary without a specific signal ("markets look weak today")
- Motivational content ("you've got this") — sounds AI-generated
- Anything that could apply to any finance account — it must be specific to CLM/CRF, the wheel, or the TQQQ desk

### The one number that matters: Discord joins per week
Impressions, likes, and follower count are vanity. Discord joins are revenue.
Track it weekly. If it's flat, the bottleneck is somewhere in the conversion path above.
